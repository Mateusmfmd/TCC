# M.O.T.I.O.N.

Aplicativo mobile de tecnologia assistiva e comunicação alternativa. O projeto busca ampliar a autonomia de pessoas com dificuldade de fala por meio de cartões de comunicação, voz sintetizada e integração com botão físico.

## Stack

- Expo e React Native
- React Navigation
- Async Storage
- Expo Speech, Image Picker, Notifications e Haptics
- Axios

## Como executar

```bash
git clone https://github.com/Mateusmfmd/TCC.git
cd TCC
npm install
npx expo start
```

Depois, escolha Android, iOS, web ou escaneie o QR Code com o Expo Go.

## Scripts disponíveis

- `npm start`: inicia o Expo
- `npm run android`: abre no Android
- `npm run ios`: abre no iOS
- `npm run web`: executa a versão web

## Contexto

Este projeto foi desenvolvido como TCC em equipe. A demonstração web está disponível em [web_tcc](https://github.com/Mateusmfmd/web_tcc).
