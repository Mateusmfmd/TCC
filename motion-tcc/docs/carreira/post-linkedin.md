Comunicar o que se quer fazer parece simples, até que falar não é uma opção.

No meu TCC do curso Técnico em Desenvolvimento de Sistemas, desenvolvi o M.O.T.I.O.N., um sistema de comunicação alternativa para crianças com paralisia cerebral.

O projeto tem um aplicativo móvel com modo responsável e modo criança (pictogramas, frases faladas, rotinas, lembretes e varredura), uma API em PHP com MySQL rodando em Docker e botões em Arduino que tocam áudios configurados no app.

Tecnologias: React Native (Expo), PHP, MySQL, Docker, Python e Arduino/C++.

Um aprendizado: acessibilidade precisa entrar desde o primeiro desenho da tela, não como ajuste no final. **[confirme]**

Código no GitHub: https://github.com/Mateusmfmd/motion-tcc
